# 案例审计：《接触的幻觉》45 秒样片与逆向解构文档

> **文档性质**：本文件是对两份外部材料的**吸收与审计记录**，不是流水线运行产物，也不代表任何门禁已被执行通过。
> **输入材料**：
> 1. 《接触的幻觉》45 秒 HTML 科普短片样片（自包含单文件，338 行 / 42,825 字节，1 个 Canvas + 1 个 SVG + 20 个函数）。
> 2. 用 SRT Media Director 流程对样片做逆向解构 + 重建规格的说明文档（约 1,241 行）。
>
> **审计方法**：对样片源码逐段人工核验，逐条比对解构文档提出的指控，并标注哪些结论可由代码证实、哪些属于设计主张。
> **边界声明**：以下所有“成立/不成立”判定仅针对**样片源码本身**；对解构文档 JSON 示例的合法性判断属预判，落地前必须做能力探测，不构成已验证结论。

## 2. 样片代码级核验

解构文档对样片提出了多项指控。以下逐条给出**基于真实源码**的核验结果（✅ 成立 / ⚠️ 部分成立 / ➕ 文档未提及的额外发现）。

### 2.1 成立的结构性事实

- ✅ **7 段场景时间轴真实存在**：`data-start`/`data-end` 依次为 `0–5 / 5–10 / 10–16 / 16–23 / 23–31 / 31–38 / 38–45`，与文档描述一致。
- ✅ **绘图函数按主题拆分**：`drawSurface / drawZoom / drawAtoms / drawForce / drawNeurons / drawReveal`，另有 `drawPrintFurniture` 每帧叠加标尺、注册十字、校准圆等图版装饰。
- ✅ **存在真实的状态插值**：`drawSurface` 中 `gap = lerp(H*.17, H*.025, smooth(p))`，间隙随幕内进度收敛——是有效的“接近”表达，而非纯装饰。

### 2.2 成立的问题（可复现）

- ✅ **seek 会重放入场动画**。`seek()` 中把 `lastScene = -1`，下一帧 `updateScene()` 因索引变化重新 `classList.toggle('active', …)`，于是 CSS 入场动画（`.scene.active .headline{animation:...}`）从头重播。拖到第 20 秒看到的不是“该时刻应有的状态”，而是“动画刚开场”。这正是文档所指的“时间线/渲染层”缺陷。
- ✅ **音频未删除**。`startSound()` 完整保留 `AudioContext` + 三个 `Oscillator`（pad/low/lfo）+ `soundLabel`，仅默认关（`SOUND OFF`）。目标是无音频影片，应删除而非默认关闭。
- ✅ **风格令牌漂移**。Canvas 绘图仍在用亮青 `#42dcff`、`#6cf3ff`、`#e8ffff`、`rgba(76,226,255,…)`、`rgba(93,212,255,…)`，与报纸纸色人格 `#286f68 / #b5523c / #eee3ca` 明显冲突。CSS 侧被 `!important` 覆盖为纸色，Canvas 侧没有。
- ✅ **硬编码比例坐标**。大量 `W*.69 / H*.51 / W*.79 / W*.955 / H*.865` 直接写在绘图函数里，布局规则未沉淀为可审计的约束数据。
- ✅ **循环而非因果的运动**。`drawNeurons` 用 `wave = (now*0.55)%1` 的循环波扫过网格，不是“刺激→感受器→脉冲→感知”的单向、有始有终的传播。
- ✅ **原子图存在行星轨道误读风险**。`drawAtoms` 中点云按 `a1 = j*2.39996 + now*(…)` 绕中心旋转，叠加多层椭圆环，容易被读成“电子沿固定轨道绕核公转”。

### 2.3 文档未提及的额外发现

- ➕ **同一 `:root` 令牌块出现两次**（第 9 行与第 40 行），文件实际叠了两代设计：早期深色科幻底（`hud` 用 `#8aa8be`、暗角 `rgba(0,0,0,.52)`）被后来的“报纸覆盖层”用一整段 `!important` 压住。这是“**缺少唯一 Style Bible**”最直接的物证——如果先有唯一风格令牌表，就不会出现两份 `:root`。
- ➕ **确定性渲染做对了**。随机粒子使用固定种子 LCG（`seed = 61273; seed = (seed*1664525+1013904223)>>>0`），因此相同 `t` 可复现相同画面。这一点文档未提及，但它是“同一 `t` 重复渲染得到相同状态”的前提，值得保留。

### 2.4 科学表述核验（初步）

- 尺度数字正确：原子核 ≈ 10⁻¹⁵ m、原子 ≈ 10⁻¹⁰ m、比例 ≈ 100,000:1。
- 表述克制：正文用“电磁相互作用**与**量子规则开始主导”，`force-legend` 同时列出 `EM FIELD` 与 `QUANTUM（泡利不相容原理）`，**没有**把泡利不相容原理单独说成所有硬度的唯一原因——符合物理层要求。
- 感知层路径正确：皮肤机械感受器把形变/刺激转成神经信号，再由中枢组织为压力/温度/疼痛。
- 结论：核心科学表述**未见明显硬伤**，但“原子轨域/概率密度的准确呈现”“材料硬度与宏观接触机制”在公开发行前仍需领域复核。

## 3. 解构文档评估

### 3.1 强项

- **诚实边界做得好**：开篇即声明“现有样片并未真正经过 `SRT → Beat Plan → … → Validation Report` 流水线”，并明确 JSON/图/报告是“应当生成的设计产物”，而非机器证据——与项目 `CORE-11/12/14`（不得把“写完代码”说成“验证完成”）一致。
- **方法论完整且可落地**：七拍状态四元组（`before → change → after → handoff`）、Visual Intent 禁止像素坐标泄漏、Scene/Relation/State/Timeline 四张图分工、L1–L4 分层验证、以及“症状 → 层级 → 修改 → 重跑 → 证据”的修复路由表。
- **优先级判断正确**：把“科学误读、绝对时间同步、镜头交接”排在“画面装饰”之前，并明确反对以粒子/光效数量作为质量指标。

### 3.2 需留意之处（落地前必须处理）

- ⚠️ **JSON 多为“示例形态”**：`interacts_with`、`propagate_once`、`converge_to_handoff` 等枚举**未必是仓库现有合法类型**，文档自身亦有承认。落地前必须先做能力探测，不能用字符串硬塞骗过 Schema。
- ⚠️ **自造目录布局风险**：文档第 20 节给出了一套 `work/` 目录布局，并自我提醒“若接现有流水线应沿用正式产物名”——应避免再造第二套互相矛盾的中间层。
- ⚠️ **修复点指认准确但需落到层**：如“seek 重放”应回到时间线/渲染层，改用绝对时间 `renderAt(t)` 驱动，而非在最终 HTML 上打补丁。

## 4. 本项目可吸收的经验

> 以下条目是本审计希望**并入本项目方法论**的部分，建议逐条对照现有 skills/ 与 runtime/ 实现确认是否已被覆盖。

1. **唯一 Style Bible 的强制物证**：把“同一颜色令牌块只允许出现一次”纳入风格层门禁；出现重复 `:root`/重复令牌即视为风格漂移失败。样片的两份 `:root` 是典型反例。
2. **真实截图探针必须进验证链**：本案再次证明“代码存在”≠“画面正确”。时间点探针 + 联系表 + L1–L4 报告应作为交付硬门槛（对应样片缺失项）。
3. **绝对时间渲染**：所有动画由单一 `renderAt(t)` 驱动，seek 与连续播放必须得到同一状态；禁止在 `seek` 中重置场景索引来重放 CSS 入场。
4. **科学视觉纪律**：把“概率密度 vs 行星轨道”“单向因果 vs 循环高亮”写成可检查的视觉断言规则（`SCHEMATIC / NOT TO SCALE` 必须显式标注）。
5. **确定性渲染正面案例**：固定种子 LCG 值得作为“同帧可复现”的推荐做法写入文档，作为时间线一致性门禁的支撑。
6. **无音频版本的 Scope 纪律**：目标为无音频时，须删除音频按钮/Web Audio/相关 UI，而非默认关闭——避免无用状态与测试面。
