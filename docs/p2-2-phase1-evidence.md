# P2-2 Phase-1 — Minimal Closed Loop Evidence

Scope (frozen): `runtime/state_delta.py` + `runtime/contracts.py` derive Delta + single entity
two states + `growth` + real renderer execution + `t0 / t_mid / t1`. The 21-case production
corpus is deliberately **not** wired to the new path yet.

## Fixture

```
Entity      : revenue_chart
State A     : value = 30
State B     : value = 70
Transition  : growth
```

| check | result |

## Evidence chain (State → Delta → Transition → Motion → Renderer)

```
identity match : same_id → revenue_chart
state delta    : value 30.0 → 70.0   (reason: revenue grew from 30 to 70)
transition     : transform           (carried + non-zero delta)
motion spec    : growth              span [0.0, 2.0] s
executor       : sample_value(t0=0.0)=30.0  t_mid(1.0)=50.0  t1(2.0)=70.0
renderer       : runtime/raster_renderer.py::draw_frame  (chart kind "growth")
frames         : frame_t0.png  frame_t_mid.png  frame_t1.png
```

Frame PNGs and their SHA-256 are recorded in `docs/p2-2-phase1-evidence/evidence.json`.
Frames are regenerated by `tools/phase1_state_delta_closure.py` and the pytest
`tests/phase0/test_state_delta_closure.py` on every run, so the evidence is reproducible
and is produced by the **real renderer**, not by inspecting JSON alone.

## Frozen-decision compliance

- `identity` is an **explicit, independent** field; never derived from the beat-scoped `id`.
  An element without `identity` is **not** treated as a cross-beat continuous entity
  (covered by `test_identity_is_explicit_not_id_derived`).
- New contract lives in `contracts/state_delta.v1.json` (behavioral contract, not `schemas/`).
- `runtime/motion` and `runtime/motion_runtime` untouched (kept for Phase 6).
- Golden baseline unchanged (additive changes only).
