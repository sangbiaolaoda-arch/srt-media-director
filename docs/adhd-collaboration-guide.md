# ADHD 协作规范（人机共用）

> **一句话**：让每一轮对话、每一份文档、每一次交接都能被快速扫描、执行、验证。
> **适用范围**：所有与 srt-media-director 协作的代理与人类。
> **边界**：本规范只约束"对话组织 / 文档组织 / 交接格式"，**不改变交付物的技术内容**。

---

## 1. 对话汇报规则（约束回复，不约束交付物正文）

1. **下一步先行**：首句给"即将执行 / 需要你决定"的行动，不铺垫背景。
2. **编号清单 ≤5 项**：多步骤用编号，每项一句话。
3. **每轮重述当前状态**：不超过两行，放在清单之前。
4. **时间估计**：每项任务标注分钟级预算；超预算 50% 先报告原因。
5. **单一下一步结尾**：结尾只给一个具体的下一步，不给多个并行选项。
6. **无开场白 / 无复述 / 无结束语**：删除"好的""如上所述""祝顺利"类套话。

## 2. 文档编写规则（交付物正文可详细）

1. **顶部一行结论（TL;DR）**，之后才展开。
2. **一级小节编号**（1. / 2. / 3.），每小节内部要点 ≤5 个。
3. **形式匹配内容**：清单表达可执行项，表格表达对比，段落只承担叙述。
4. **长文分节 + 锚点**：禁止无标题长段落。
5. **状态类文档**（进度 / 交接 / 审计）必须含：已完成 / 未完成 / 下一步 / 风险 四段。

## 3. 交接契约

跨轮次交接必须显式包含四段，缺一视为不完整，接收方有权要求补齐：

- **已完成**：列 3 项内。
- **未完成**：列 3 项内，注明阻塞原因。
- **下一步**：唯一一项。
- **风险**：如无写"无"。

## 4. 与现有方法论的接合

- **grill-me**：任务开始先对齐目标 / 范围 / 验收 / 约束 / 产物位置（复述 ≤5 行）。
- **andrej-karpathy**：不过度自信、不提前宣布完成、以仓库原文为准。
- 本规范不替代上述方法论，只在其之上补充"输出组织纪律"。

## 5. 时间预算约定

- 计划阶段为每步标注分钟预算（如 `15min`）。
- 实际执行超预算 50% 时，先报告原因再继续。
- 批量任务（如全量测试）以运行时长而非人工时长计时。
