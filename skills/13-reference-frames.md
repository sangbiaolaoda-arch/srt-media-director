# 13 · Reference Frames（参考帧构图语法）

> v7.1 新增、v7.2 重构为**规则引擎**。**把参考帧「手写 SVG 的构图代码」学成可复用规则**，
> 而不是只抄配色、更不是只复现三张图。机器实现：`runtime/ref_frame.py`（门禁 G16）。
> 关联规则：`06-composition`、`05-global-grammar`、`11-visual-grammar`、`07-choreography`。
> 机器实现：`runtime/ref_frame.py`（门禁 G16）。

## 一句话

**学构图，不是学配色。**

用户给出的三张参考帧（`frame_01_hook` / `frame_02_cause_chain` /
`frame_03_comparison`）是**手写 SVG 的信息图**。真正要复刻的是它们的
**构图语法**——版心网格、圆角卡片、线稿图标、连接箭头、强调纪律——
以及**逐元素入场编排**。只改颜色不算学会。

## 参考帧提炼出的设计系统（从原始 SVG 精确抽取）

| token | 值 | 角色 |
|---|---|---|
| bg | `#F3F2EF` | 画布底（warm grey） |
| panel | `#FAFAF8` | 卡片 / 主体填充 |
| ink | `#2B2B2B` | 主描边 + 主文字（≈12:1） |
| neutral | `#8A8A86` | 次级描边（≈3:1） |
| muted | `#6B6B67` | 次级文字（≈4.9:1） |
| accent | `#C4452B` | **每帧仅一处、仅一个元素** |
| line | `#D3D2CD` | 灰填充 / 分隔 |

- 描边阶梯：**primary 2 / 2.25**，**secondary 1.25 / 1.5 / 1.75**。
- 字号阶梯：**12 / 13 / 14 / 15** + 标题 **26 / 34**（weight 500）。
- 字体：`PingFang SC / Noto Sans CJK SC / Microsoft YaHei`——**无衬线**。
- 版心：`viewBox 0 0 680 382`（16:9），**左 48px，标题同 x 对齐**。

## 三种构图型 ↔ 三种视觉语法

| 参考帧 | 语法操作 | `ref_frame` 函数 | 结构 |
|---|---|---|---|
| frame_01_hook | establish | `frame_hero` | 大问句(34) + 副题(15) + 主体意象 + 单强调 |
| frame_02_cause_chain | causality / progression | `frame_chain` | 三节点横排 + 连接箭头；中节点主（2.25） |
| frame_03_comparison | contrast | `frame_compare` | 双面板 + 基线柱；右面板主 + 唯一强调柱 |

补充型：`frame_statement`（纯命题大字）、`frame_bar_detail`（单进度条详情）。

## 强调纪律（不可违背）

1. **强调 = 加粗描边（2.25）+ 加深/加粗文字**，不靠换色。
2. **每帧 accent 只花一次**（一个元素）。它是稀缺资源。
3. 次级元素统一用同一个灰（`neutral`/`muted`），不要给每个元素不同颜色。

## 逐元素入场编排（重点）

构图不是一张死图。每个元素独立成**图层**，各自错峰入场：

```
每个 frame_* 返回 {bg, elements:[{id, svg, box, motion, at}]}
  svg    = 只含该元素的整幅透明 SVG（画布对齐）
  box    = 包围盒 (x,y,w,h)，viewBox 单位
  motion = rise | fade | pop | draw | grow
  at     = 进场起始秒（None → 按阅读顺序自动错峰）
```

| motion | 用于 | 动作 |
|---|---|---|
| `rise` | 标题 / 文字 / 脚注 | 上浮淡入 |
| `fade` | 面板 / 卡片 | 纯淡入 |
| `pop` | 图标 / 节点 | 缩放弹入 |
| `draw` | 箭头 / 基线 / 刻度 | 从左向右画入 |
| `grow` | 柱子 / 进度条 | 从底向上长出 |

**这直接回应「Fade In 不算动画设计」（CORE-04）**：整拍淡入是偷懒；
逐元素入场才是「状态变化优先于动作数量」。

## 硬纪律（机器门禁 G16）

1. 每个 `frame_*` 必须返回 `{bg, elements:[{id,svg,box,motion,at}]}` 结构。
2. 每个元素的 `motion` 必须在合法集合内；`box` 必须是四元组且在画布内。
3. 一帧的 accent 出现次数 ≤ 1（强调预算）。
4. 每个元素必须能被独立渲染成透明图层（构图必须是「图层可分离」的）。

# 附录：代码经验总结（从「抄三张图」到「生成引擎」）

> v7.2 追加。这一节才是「学会」的证明——**把三帧手写 SVG 里可迁移的工程经验抽干**，
> 让它能生成作者没画过的新构图。

## 教训：照抄 vs 学会的分界线

| 维度 | 照抄（模板动物园） | 学会（规则引擎） |
|---|---|---|
| 坐标 | 写死 `x=[48,265,482]` | `cols(3)` 公式 **解** = 那个坐标 |
| 列数 | 只能 3 列 | `cols(n)` 任意 n，仍贴版心不重叠 |
| 图标 | 5 张固定贴图 | 参数化函数 `icon(cx,cy,scale,col)` |
| 换内容 | 版式崩 | 版本不变、内容替换 |
| 新构型 | 做不出 | 四象限 / 时间轴 / 纵向清单 |
| 门禁 | 无 | G16：复现 + 泛化双断言 |

**判据**：一条规则若只能还原它被抽出的那张图，它就是「抄」；
若它还能**外推**出源图没有的解，它才是「学」。

## 七条可迁移经验

1. **令牌即契约。** 颜色/线宽/字号抽成 token，别让魔法数字散落在 SVG 里；
   换主题只改一处令牌表。
2. **坐标是规则的解，不是字面量。** 列位置 = 版心 + 槽宽公式。`3` 只是这条
   公式的一个取值；写死数字=丢掉公式。
3. **强调是预算，不是样式。** accent 是稀缺资源，每帧只花一次，且只落**一个元素**
   （含强调色的**元素个数** ≤ 1，而非颜色串出现次数）。
4. **强调靠权重差异（加粗 + 加深），类别才靠换色。** 权重编码层级、颜色编码类别，
   两者正交——不要用换色冒充强调。
5. **构图 = 可分离图层集合。** 每个元素独立成整幅透明 SVG + 包围盒；这是逐元素
   入场动画的前提（整拍淡入 = 没有编排）。
6. **入场是有限词汇。** `rise|fade|pop|draw|grow` 按元素语义分配（文字上浮、面板淡入、
   图元弹入、箭头画入、柱子长出），不是每拍整体淡入。
7. **图元是函数不是贴图。** 图标形参化 `(cx,cy,scale,col)` 才能复用到新构图；
   固化坐标的图标只能待在原图里。

## 外推验证（机器 + 视觉双证据）

- **机器**：`self_test.py` G16 —— 同一 `cols()` 既给出参考帧精确坐标，又对
  `n=2/4/5` 保持「贴版心、无重叠」合法；`frame_quadrants/timeline/stack`
  三个**参考帧没有**的构型全部通过图层规范校验。
- **视觉**：`tools/_build_generalize.py` 渲染「上排复现 / 下排外推」并排图
  （`ref-rule-generalize.png`），外推帧与复现帧结构差异显著，证明不是同图套色。

结论：**能复现只说明会抄；能外推、能被门禁约束，才是真学会。**
