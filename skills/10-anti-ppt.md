# 10 · Anti-PPT：防退化门禁

> 本模块是质量底线清单：防止流水线「技术上全过、产物却是字幕 PPT」。
> 约束：CORE-03 / CORE-11 / CORE-15 · 与 L4 审查（09）配合执行

## 1. 什么是「PPT 化」

PPT 化的判据不是「元素少」，而是**画面没有承担字幕之外的信息工作**：

- 每拍都是「标题 + 正文 + 居中插图」，模板不换；
- 字幕原文被放大当画面主体，遮住字幕后画面不再传达任何信息；
- 所有元素一起 fade in，然后静止到下一拍；
- 图表/图形是装饰：遮住它观众没有任何损失；
- 全片看完记不住任何一个「画面」。

## 2. 机器可查的退化信号（已进入 validator / self_test）

| 信号 | 门禁 | 出处 |
|---|---|---|
| 每拍 > 1 个 primary（=没有重点） | R1 / L1 PRIMARY_COUNT | 06 |
| 邻拍同模板（=版式复读） | R8 | 06 |
| 尾段空窗 > 20%（=静止等待） | G3 | 07 |
| 帧墨水量越界 / 颜色数过低 | L3 ink_ratio / distinct_colors | 09 |
| 元素 fade in 后无任何状态变化 | TRANS-02（事件词汇表审查） | 04/07 |
| cue 覆盖缺失（=丢字幕） | L1 BEAT_COVERAGE | 01 |

## 3. 需要 L4（人/Agent 看样例）判断的退化信号

- **PPT-L4-1** 遮住字幕测试：只看画面，能否复述这一拍的命题？
  不能 → claim 不成立，回 `04` 层。
- **PPT-L4-2** 模板多样性：全片 8 拍少于 4 种模板（GRAM-10）→
  按「疑似 PPT 化」打回导演层。
- **PPT-L4-3** 图形必要性测试：逐个遮住非文本元素，若遮住后理解无损，
  该元素是装饰——删除或赋予它信息工作（CORE-15 的反向应用：
  不堆元素，但留下的每个元素必须有工作）。
- **PPT-L4-4** 记忆点测试：看完样例，能说出至少一个具体画面
  （「20% 那个环形」「15→45 那对柱子」）吗？不能 → 全片没有强调终点，
  回 `03` 层重做强调计划。

## 4. 合法的「简洁」

CORE-15：简洁画面可以 PASS。一拍只有「一个大数字 + 环形图 + 一行注脚」
是完全合法的——只要它通过：

1. 遮住字幕测试（画面独立传达命题）；
2. 每拍一个明确的注意力终点；
3. 有真实的状态变化（数字生长/颜色洗入/关系建立）；
4. 与邻拍的构图模板不同。

**Anti-PPT 反对的不是简单，而是「画面不工作」。**

## 5. 惰性复用检测（素材纪律）

- **LAZY-01 [强制]** 同一 motif 跨拍复用必须给出连续性理由
  （carry_over 的 reason 字段）；「方便」「差不多」不是理由（CORE-24）。
- **LAZY-02 [经验]** 每拍至少一处**场景级新鲜信息**（NARR-03）：
  新结构 / 新信息层 / 新转化状态 / 新自绘图形。全片复用同一构图
  只换文字 = 最高级别的 PPT 化。
